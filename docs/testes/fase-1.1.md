# Testes da fase 1.1 (build 6 ou mais nova)

Marque cada item com `[x]` (deu certo) ou `[ ]` com um comentário. Quando um jogo não abrir: painel de baixo > aba Telas > "Copiar relatório", e cole junto.

Versão testada (painel de baixo, aba Ajustes, no fim): `Huginn 0.0.__ · build __`

## 1. Painel de baixo ao fechar
Teste com o Huginn **não** sendo o launcher padrão.
- [ ] Fechar o Huginn pelos recentes (arrastar) fecha o painel de baixo também.
- [ ] Apertar Home (indo para o seu launcher) fecha o painel de baixo.
- [ ] Abrir um jogo pelo Huginn **não** fecha o painel de baixo.
- [ ] Abrir o Huginn de novo pela lista de apps traz o painel de volta.

## 2. Emuladores encontrados
- [ ] Aba Ajustes > "Emuladores encontrados" lista os emuladores que você tem instalados, com ícone e consoles. Falta algum? Qual?
- [ ] Em "Emulador por console", cada console mostra o emulador que você instalou para ele (o próprio, não o RetroArch, quando você tem os dois).

## 3. Liberar a pasta de ROMs
- [ ] Na aba Ajustes, sua pasta aparece como "ainda não liberada para os emuladores", com o botão "Liberar para emuladores".
- [ ] O botão abre o seletor do Android já na pasta; tocando em "Usar esta pasta" e permitindo, a pasta passa a aparecer como "liberada".
- [ ] Se você não liberar antes: ao jogar pela primeira vez com melonDS, Dolphin, Azahar, DraStic, PPSSPP ou DuckStation, o Huginn avisa e abre o seletor. Depois de liberar, o jogo abre.
